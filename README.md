# 阅读社统导工作台

平台按期次管理飞书推书和选书问卷，并负责分组预览、写回确认、历史保存和 CSV 下载。

## 期次表约定

每期在同一个飞书 Base 中创建两张独立数据表：

- `推书汇总｜YYYY-MM`：绑定 `YYYY-MM 荐书表单`；
- `选书汇总｜YYYY-MM`：绑定 `YYYY-MM 选书表单`。

工作台输入期次后会自动发现对应表；缺失时可点击“初始化本期”一次性补齐数据表、字段和表单。分组只读取该期选书表，确认后把有效状态和组号写回同一张表。

从项目根目录运行：

```bash
npm run app
```

前端地址：`http://localhost:3000`。
